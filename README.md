# Shashank Singh Bisht — Portfolio

A responsive, single-file personal portfolio and CV site. The page is implemented in `index.html` with embedded HTML, CSS, and JavaScript.

## Preview locally

Open `index.html` in a browser, or serve the folder locally:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). The page loads its fonts from Google Fonts, so those fonts need an internet connection.
